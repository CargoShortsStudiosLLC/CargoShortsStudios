# Cargo Shorts Studios

Boilerplate static site, currently showing an "under construction" placeholder.

## Local preview

Open `index.html` directly in a browser, or serve it:

```bash
python3 -m http.server 8000
```

## Hosting

Deployed via GitHub Pages using the workflow in `.github/workflows/deploy.yml`, which publishes the repo root on every push to `main`. Enable Pages in the repo settings (Settings → Pages → Source: GitHub Actions) after the first push.
